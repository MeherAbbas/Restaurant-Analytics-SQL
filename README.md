# Restaurant Analytics Using SQL

## Project Overview
This project explores restaurant-related data using SQL to practise data cleaning, data validation, querying, and business analysis. It was developed as a learning and portfolio project.

## Tools
- MySQL
- MySQL Workbench

## SQL Skills Practised
- Data cleaning and validation
- Filtering and sorting with `WHERE` and `ORDER BY`
- Aggregations such as `COUNT`, `SUM`, and `AVG`
- `GROUP BY` and `HAVING`
- Conditional logic with `CASE`
- Joins
- Subqueries
- Common Table Expressions (CTEs)
- Window functions, including ranking and `LAG()` where applicable

## Project Workflow
1. Created and reviewed restaurant-related tables.
2. Inspected the data and checked for quality issues.
3. Used SQL queries to filter, summarize, and compare records.
4. Applied advanced SQL techniques to answer analytical questions.
5. Interpreted query results to identify useful patterns.
